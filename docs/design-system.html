Delforte · lib/design_system

Vigil

Galeria do design system do Delforte, o app de orçamentos para instaladores de cerca elétrica. Fundações, componentes e telas, desenhados em HTML/CSS a partir do código Flutter atual.

O bloco :root deste arquivo é o contrato de tokens: um teste Dart compara cada --color-* com VigilColors. Funciona offline; as fontes vêm de assets/fonts.

Fundações

Valores de colors.dart, type.dart, space.dart, radius.dart, stroke.dart, shadow.dart e gradients.dart.
